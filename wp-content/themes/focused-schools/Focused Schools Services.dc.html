Long-content & empty-field behavior

  • Title wraps at 18ch, up to three lines, before it hits the media column. Longer titles reduce to 44px at the 1240 breakpoint anyway.
  • Tagline is a hard 30ch measure; editors get a 110-character soft limit in the admin field description. It never truncates — it wraps.
  • Description measure is 62ch. Past ~160 words the block simply grows; the media stays top-aligned via align-items: start, so no vertical centering drift.
  • Offerings render in two columns from four items up, one column below four and on mobile. Eight is the practical ceiling; past that, the section grows and the block stays legible.
  • No offerings → the label, the hairline, and the 30px padding all disappear; the CTA moves up. No empty rule left behind.
  • No featured image → the figure collapses and the copy column spans full width at a 70ch measure. Alternative fallback (needs approval): teal tile with the mark at 7%.
  • No CTA → button is omitted; page-level closing CTA still catches the reader.

Scaling to N services

  • Grounds alternate white / paper by index parity — never hard-coded per service.
  • Media side alternates by the same parity, so adding a service in the middle reflows the rhythm automatically.
  • Index numerals are generated from loop position, so reordering in WordPress renumbers the page.
  • The jump index above is the same query, so a new service appears in both places at once.
  • Accent falls back to teal #005C6D if the field is empty — never to a random color.
  • At 6+ services, switch the jump index to a sticky rail (documented, not built) rather than lengthening the list.

Mobile behavior

Single column at <768px, 20px gutters, section padding 64px. The lane block always stacks copy → offerings → CTA → image: the image is evidence, not the headline, so it never pushes the promise below the fold.

Image guidance

  • Hero 21:9, min 2400×1030, focal interest right of center so the slab never covers a face. Eager + fetchpriority="high".
  • Lane featured image 4:5, min 1000×1250, 8px radius, shadow 0 20px 44px rgba(0,92,109,.14). One person or one team in the act of working — no posed grip-and-grins, no stock.
  • Mobile hero uses the same file with a 4:5 art-directed crop via <picture>, not CSS cropping.
  • Documentary color photography only: no duotone, no grayscale, no filters, no gradient scrims outside the hero.
  • Every image carries real alt text describing the work, not the brand. Decorative marks get alt="".
  • WebP with JPEG fallback, width/height attributes on every <img> to hold layout.

The three lane images here are placeholders pulled from the approved homepage retreat set. Each lane wants its own photograph so the page does not repeat the homepage imagery.

Developer notes (WordPress)

  • CPT: fs_service, public, page-attributes support for menu order, archive off. Single template optional — the page is the canonical view; if singles ship later they reuse this same block at full width.
  • Fields (ACF): tagline (text), short_description (textarea), signature_offerings (repeater, one text sub-field), featured_image (native), cta_label + cta_link (link field), accent (select: cerulean / coral / lime / teal).
  • Accent is a token key, not a hex. The select stores cerulean; the template maps it to var(--fs-cerulean). Editors can never enter a color.
  • One template part: template-parts/blocks/service-lane.php, looped by WP_Query ordered by menu_order. Ground and media side derive from $index % 2. The jump index runs the same query and prints anchors from post_name.
  • Editor guardrails: no per-service layout toggle, no color picker, no rich text in tagline. Section wrapper exposes ground + padding only, per DS v1 handoff.
  • Anchors: #{post_name} with scroll-margin-top: 106px to clear the sticky header.
  • A11y: one h1 (hero), lane titles are h2, offerings label is a p not a heading; jump index is a nav with an accessible name; images lazy except the hero.
  • Zero new CSS beyond the offerings list and the accent bar utility. Everything else is existing homepage classes.
